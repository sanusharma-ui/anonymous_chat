# Stranger Chat App 💬

A real-time stranger chat app built with **Node.js + Express + Socket.IO**.  
Supports both **Random Stranger Chat** (Omegle style) and **Private Room Chats**.

---

## 🚀 Features
- Random stranger pairing
- Create & join private rooms
- Typing indicators
- Partner left detection
- "Next" button to skip partner
- Responsive frontend (to be added)
